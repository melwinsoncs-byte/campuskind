# CampusKind 🌿

**Good habits. A greener campus.** A student-powered demo that makes campus plastic reduction easy to see and easy to join.

## Try the demo

- Log a refill, reusable cup, or skipped plastic bag.
- Track personal items avoided and your daily streak.
- Explore example refill spots and a friendly house leaderboard.

Personal activity is stored locally in the browser on your device.

## Deploy

This static site is published with GitHub Pages from the **main** branch and the repository **root**. To change the publishing source, open **Settings → Pages**.

## Demo data

Campus totals, house scores, and refill locations are examples. Replace them with verified information for your campus before presenting them as real data. A campus-wide tracker would need a shared data source.
