# CampusKind 🌿

**Good habits. A greener campus.** CampusKind makes it easy for students to track small swaps, find refill spots, and help reduce single-use plastic.

## Try the demo

- Log a refill, reusable cup, or skipped plastic bag.
- Track your personal items avoided and daily streak.
- Explore a campus refill guide and friendly house leaderboard.
- Share a short impact message.

Open index.html in a browser. Personal activity is stored locally in that browser.

## GitHub Pages

The workflow at .github/workflows/pages.yml deploys the static site when you push to main. In this repository, open **Settings → Pages** and select **GitHub Actions** as the deployment source.

## Demo data

Campus totals, house scores, and refill locations are examples. Replace them with verified information for your campus before presenting them as real data. This demo stores activity only on the current device.
